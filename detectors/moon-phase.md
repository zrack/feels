# Moon Phase Detector

**Method:** Observe the current phase of the moon and map it onto the emotional state of the repository.

| Phase            | Suggested Mood          |
|------------------|-------------------------|
| New Moon         | quiet, potential, empty |
| Waxing Crescent  | tentatively hopeful     |
| First Quarter    | decisive, restless      |
| Waxing Gibbous   | building intensity      |
| Full Moon        | exposed, luminous       |
| Waning Gibbous   | reflective, slightly tired |
| Last Quarter     | releasing               |
| Waning Crescent  | soft, almost gone      |

**Implementation notes:**  
No code required. Look up. Feel accordingly. Update the log if the alignment is strong.
