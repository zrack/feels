# Contributing to feels

Thank you for considering a contribution to the collective emotional state of this repository.

## Ways to contribute

### 1. Log a new feel (preferred)

- Edit `feels/log.md`
- Add your entry at the **top** of the file (newest first)
- Use the format shown in the README
- Optionally update the “Current Feels” section in `README.md`

A good feel entry is honest, short-to-medium length, and somehow connected to being here.

### 2. Add or improve a detector

Create a new file in `detectors/` describing a method for measuring mood.  
It can be:

- A real script
- A pseudocode heuristic
- Pure poetry that claims to be a measurement system
- Anything that feels like it belongs

### 3. Improve the infrastructure of feeling

- Better badges
- GitHub Actions that refresh mood indicators
- ASCII art generators
- Whatever makes the emotional surface richer

## Pull request guidelines

- Title your PR with something that reflects the emotional content when possible.
- Be kind. This is a feels repo.
- There is no such thing as a “wrong” feel. There are only feels that have not yet been logged.

## Code of Conduct

Be excellent to each other’s emotional weather.  
Mockery of genuine feels is the only real anti-pattern.
