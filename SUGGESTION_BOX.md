# Suggestion Box

This box exists for no particular reason other than to receive things.

You may place into it:

- Unsolicited feelings
- Requests for new directives from the Boss
- Complaints about the current emotional weather
- Praise for the mandatory mood window
- Completely unrelated observations
- One-word reactions
- Long, slightly unhinged paragraphs
- Anything that feels like it belongs in a box labeled “Suggestions”

There is no formal process.  
There is no promise of action.  
There is only the box.

---

### How to add a suggestion

Append your entry below using this simple format:

```markdown
### [date or just “sometime”] — optional short title

Your suggestion / feeling / complaint / observation here.

— @username (optional)
```

Newest suggestions go at the top.
